# 1. 硬件信息

所有实验均在单张 `NVIDIA A100 Tensor Core GPU` 上完成。

# 2. 数据准备

数据预处理的相关代码及说明位于 `DataProcessProject` 文件夹下。请先阅读该文件夹中的 `README` 文件，并按照指引完成实验。确认数据准备无误后，方可进入下一步。

# 3. 虚拟环境配置

根据不同的实验需求，我们提供了两套虚拟环境配置：

- **时序基础模型**：详见 `TS-LibProject` 文件夹，**需使用 Python 3.8**。
- **时序大模型**：详见 `LLMProject` 文件夹，**需使用 Python 3.10**。

具体的依赖包信息（`requirements.txt`）请参见对应子文件夹。

我们推荐使用 `conda` 管理虚拟环境，可大幅简化环境配置过程。`conda` 的具体使用方法请自行查阅相关文档。

# 4. 复现指南

本项目的模型复现主要分为两个部分：

- **Part 1：时序基础模型复现**（详见 `TS-LibProject` 文件夹）
- **Part 2：时序大模型复现**（详见 `LLMProject` 文件夹）

各部分的详细复现步骤请参见对应文件夹下的 `README.md` 文件。
